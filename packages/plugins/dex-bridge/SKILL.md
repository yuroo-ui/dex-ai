# Dex Bridge Plugin

Skills for cross-chain bridging, swapping, and asset transfer across all chains.

## Included Skills

| Skill | Description |
|-------|-------------|
| bridge-lifi | Li.Fi API — bridge & swap across 30+ chains |
| bridge-relay | Relay Protocol — fast cross-chain messaging |
| bridge-any | Universal bridge patterns & aggregators |

## Supported Chains

EVM: Ethereum, Polygon, Arbitrum, Optimism, Base, BSC, Avalanche, Fantom, zkSync, Linea, Scroll, Mantle, Blast, Fraxtal, Mode, BOB, Zora, and more.
Non-EVM: Solana, Bitcoin, Sui, Starknet.

## Installation

```bash
/plugin install dex-bridge
```
