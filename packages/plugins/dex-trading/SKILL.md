# Dex Trading Plugin

Skills for integrating DEX swaps, routing, and MEV protection.

## Included Skills

| Skill | Description |
|-------|-------------|
| swap-integration | Integrate swaps via Router, SDK, or API |
| mev-protect | Protect transactions from MEV bots |

## Installation

```bash
/plugin install dex-trading
```

## Requirements

- Node.js >= 20
- ethers.js v6 or viem
- RPC endpoint (Alchemy, Infura, or public)
